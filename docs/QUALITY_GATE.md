# Quality Gate — 页面级强制自检

每一页在交付前都必须通过以下检查。任何一项明显失败，都不能标记为最终稿。

## 1. 版式与对齐
- 标题、正文、图片、图标、功能框是否对齐
- 元素间距是否稳定
- 留白是否接近原稿
- 是否出现无意义挤压或过度放大

## 2. 背景与融合
- 是否保留原始环境氛围、纹理、烟雾、光影
- 内容板块是否与背景割裂
- 人物是否有抠图感、白边、硬边
- 是否存在重影
- 是否有原稿应存在的硝烟 / 雾效融合

## 3. 图像与裁切
- 替换图是否保持正确比例
- 是否擅自改变用户指定大小
- 是否裁掉关键人物 / 内容
- 是否缺失原稿功能框右侧、角落等关键图片

## 4. 字体与文字
- 字体是否真实可获取
- 字号、字重、行距、字距是否接近原稿
- 中文是否出现错字、乱码、字体替换
- 艺术字是否尽量保留可编辑性

## 5. 色彩与光影
- 主色、辅助色是否与原稿一致
- 高光、阴影方向是否合理
- 人物与环境色温是否统一
- 不得擅自增加新的设计风格

## 6. 可编辑性
- 标题、正文、标签是否为文本对象
- 简单框、线、图标是否为原生形状
- 可重建图表是否避免直接截图
- 不得用整页大图冒充可编辑 PPT

## 7. 导出检查
- 16:9 等页面比例是否正确
- 导出预览无锯齿、裁切、错位
- 无超出画布的意外元素
- 无透明度、阴影、字体导致的异常

## 8. 最终判定
建议页面记录：
- Visual Fidelity：0–100
- Editability：0–100
- Background Integration：PASS / FAIL
- Typography：PASS / FAIL
- Alignment：PASS / FAIL
- Export：PASS / FAIL

最低目标：
- Visual Fidelity >= 90
- Editability >= 80
- 所有 PASS 项均通过
