# Quality Gate — 页面级强制自检 v2

每一页在交付前都必须通过以下检查。任何一项明显失败，都不能标记为最终稿。

## 1. 版式与对齐
- 标题、正文、图片、图标、功能框是否对齐
- 元素间距是否稳定
- 留白是否接近原稿
- 是否出现无意义挤压或过度放大
- 同类组件尺寸、间距、基线是否一致

## 2. 背景与融合
- 是否保留原始环境氛围、纹理、烟雾、光影
- 内容板块是否与背景割裂
- 人物是否有抠图感、白边、硬边
- 是否存在重影
- 是否有原稿应存在的硝烟 / 雾效融合
- 背景与内容区交界是否出现矩形硬切

## 3. 图像与裁切
- 替换图是否保持正确比例
- 是否擅自改变用户指定大小
- 是否裁掉关键人物 / 内容
- 是否缺失原稿功能框右侧、角落等关键图片
- 是否发生非必要拉伸
- 图片窗口是否采用正确裁切而非变形适配

## 4. 字体与文字
- 字体是否真实可获取
- 字号、字重、行距、字距是否接近原稿
- 中文是否出现错字、乱码、字体替换
- 艺术字是否尽量保留可编辑性
- 同层级标题 / 正文的字体规范是否一致

## 5. 色彩与光影
- 主色、辅助色是否与原稿一致
- 高光、阴影方向是否合理
- 人物与环境色温是否统一
- 不得擅自增加新的设计风格
- 卡片、功能框是否因为过白 / 过亮与环境割裂

## 6. 可编辑性
- 标题、正文、标签是否为文本对象
- 简单框、线、图标是否为原生形状
- 可重建图表是否避免直接截图
- 重复模块是否组件化而非整组图片化
- 不得用整页大图冒充可编辑 PPT

## 7. 内容完整性
- 原稿中的关键人物、图片、图标、功能框是否完整保留
- 是否遗漏边角装饰、右侧图片、编号、标签等重要元素
- 用户要求保留的内容是否 100% 存在
- 是否产生重复人物、重复阴影、重复光效

## 8. 用户修改范围
当用户给出局部修改指令时：
- 是否只修改被授权对象
- 未授权对象的位置、尺寸、字体、颜色是否保持不变
- “不改大小”等明确约束是否严格执行

## 9. 导出检查
- 16:9 等页面比例是否正确
- 导出预览无锯齿、裁切、错位
- 无超出画布的意外元素
- 无透明度、阴影、字体导致的异常
- 导出结果与编辑视图是否一致

## 10. 页面评分
每页建议记录：
- Visual Fidelity：0–100
- Editability：0–100
- Content Completeness：PASS / FAIL
- Background Integration：PASS / FAIL
- Typography：PASS / FAIL
- Alignment：PASS / FAIL
- Image Crop：PASS / FAIL
- Scoped Edit Compliance：PASS / N/A / FAIL
- Export：PASS / FAIL

最低目标：
- Visual Fidelity >= 90
- Editability >= 80
- Content Completeness = PASS
- 所有其余适用 PASS 项均通过

## 11. Deck-level 全局检查
多页项目最终还必须检查：
- 页面间字体系统是否一致
- 相同组件是否出现多个不一致版本
- 标题层级是否稳定
- 色彩是否漂移
- 图片质量是否参差
- 边距和页面节奏是否统一

只有页面级和整套级检查均通过，才允许标记为 FINAL。
